# 今日食养

一个无需安装依赖的中文每日食谱推荐原型。根据身高、体重、年龄、生理性别、活动量和体重目标，估算每日热量与三大营养素，并按目标热量动态调整食材份量。内置 112 道分餐菜谱，连续换一组时会避开上一组菜品。

点击任意菜谱卡片可查看按当前目标份量生成的食材清单、预计时间、详细烹饪步骤和健康小贴士。

支持本地账号注册与登录。每个账号会独立保存身体数据、活动量和目标，重新登录后自动回填。账号、密码摘要和档案仅存储在当前浏览器；如需跨设备同步，应接入服务端身份验证与数据库。

## 使用

直接用浏览器打开 `index.html`。

也可以在此目录启动静态服务器：

```powershell
python -m http.server 8000
```

随后访问 `http://localhost:8000`。

运行本地账号流程测试：

```powershell
node tests/auth-flow.test.cjs
```

## 计算说明

- 基础代谢：Mifflin–St Jeor 公式
- 维持热量：基础代谢 × 活动系数
- 减脂：维持热量的 85%；增重：维持热量的 110%
- 每日热量保护下限：女性 1200 kcal，男性 1500 kcal
- 仅供一般成年人的健康管理参考，不构成医疗或营养诊断
